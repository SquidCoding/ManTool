# ManTool
CLI Personnel management tool written in C++
---
# Why Was This Made?
I wanted to create a useful piece of software as both a learning exercise to build my C++ knowledge

# What Does It Do?
+ Adding Organization Members:
  * Users are able to create employee profiles, complete with the following information:
    - Organization Name
    - Department Name
    - Employee Name
    - Employee ID
    - Superior's ID
    - Job Title
    - Payment Type (Salary/Hourly)
    - Payment Ammount
+ Search Through Your Employees:
  * Users are able to search through their organization(s) by the following criteria:
    - Department
    - Employee Name
    - Employee ID
    - Job Title
    - Payment Type
+ Display Your Organization Hierarchy:
  * Users are able to display their organization's hierarchy either in its entirety or by department
+ Export Data:
  * Users are able to export their organization's member data in a TSV format at either the organization or department level
+ Import Data:
  * Users are able to import organizations using unique .organ files
