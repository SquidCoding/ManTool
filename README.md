# ManTool
Personnel management tool written in C++
---
# Why Was This Made?
I wanted to create a useful piece of software as both a learning exercise to build my C++ knowledge

# What Does It Do?
+ Adding Organization Members:
  * Users are able to create employee profiles, complete with the following information:
    - Organization Name
    - Department Name
    - Employee Name
    - Job Title
    - Payment Type (Salary/Hourly)
    - Payment Ammount
    - General Notes
+ Search Through Your Employees:
  * Users are able to search through their organization by the following criteria:
    - Organization
    - Department
    - Employee Name
    - Job Title
    - Payment Type
    - Payment Ammount (range)
+ Display Your Organization Hierarchy:
  * Users are able to display their organization's hierarchy either in its entirety or by department
+ Export Data:
  * Users are able to export their data in a TSV format at either the organization or department level
